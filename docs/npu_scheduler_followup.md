# NPU 스케줄러 후속 로드맵 (Stage 5)

## 요약
정확도 가드 및 관측 지표 확장을 Stage 5에서 마무리했으므로, 스케줄링 정책과 배치 전략을 고도화하기 위한 후속 과제를 정의한다.

## 우선순위 제안
1. **WFQ/EDF 정책 프로토타입**: 현재 RR/우선순위 기반 정책을 확장하여 가중치 또는 데드라인 기반 분배를 실험한다. 구성 플래그는 `npu.policy` 하위에 추가한다.
2. **Dynamic Batching 실험**: CQ 입력 경로와 연계해 DMA 통합·메모리 예약을 재검토하고, 배치 크기 조정이 대기 지표에 미치는 영향을 측정한다.
3. **지표 자동화**: `wait_metrics`와 `cpu_metrics`를 활용해 벤치마크 모드에서 자동 리포트를 생성하고, 회귀 대시보드(예: JSONL 로그)를 구축한다.
4. **골든 관리 자동화**: 워크로드별로 골든 파일을 재생성하는 스크립트를 추가하고 CI에서 주기적으로 검증한다.

## 의존 관계
- WFQ/EDF 구현은 `NPUCluster`의 코어 선택기와 DMA 플로우 제어가 안정화된 이후에 진행한다.
- Dynamic Batching 실험에는 CQ 경로 테스트(`run-cq`)가 필수이므로 Stage 4 자산을 활용한다.

## 완료 시 검증
- 각 정책/기능 도입 시 `pytest tests/performance --benchmark-only` 실행 결과와 정확도 가드 통과 여부를 기록한다.
- 골든 재생성 스크립트는 `make regenerate-goldens` 또는 동등한 명령으로 통합하는 것을 목표로 한다.
